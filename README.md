# 哲学库 · philosophy-library

一个自建的哲学语料库技能：**它不替你想，它告诉你某句话在哪一页。**

## 它解决什么问题

问 AI「康德怎么看待痛苦」，你会得到一个很像样的段落，但**没有任何一句可以核对**——不知道出自哪本书、哪一版、哪一页。哲学写作最需要的那一层，恰好是模型最容易编造的那一层。

这个库把这件事反过来做：

- 原文按章存进来，每页留页码标记
- 每条回答必须带坐标 `〔作者·《著作》·章节，p.187〕`
- 库里没有的，直说没有，不许凭记忆补

**它的价值不在于知道得多，而在于说得出每一句的出处。**

## 里面有什么

```
地图.md 116 个哲学史节点，16 个时期、41 条线索，外加 42 条关系边
排序规则.md 节点凭什么排在那个位置：时期 → 线索 → 生年
library/01-sources/ 一手文本，按章切分，PDF 保留纸书页码标记
library/02-excerpts/ 摘录与划线
library/03-judgments/ 自己的判断（与原文分开存放，永不混写）
library/04-themes/ 主题连线
scripts/ 14 个脚本，见下表
config/ 排序归属、合法书源
```

**四类条目分开存**是这个库的骨架：原文怎么说的、后来谁怎么解释的、你自己怎么判断的——三样东西不许穿同一件衣服。

## 怎么用

```bash
# 需要 PDF 抽取时才装，其余功能零依赖
pip install pymupdf

python scripts/probe.py "D:/书/xxx.pdf" # 先体检：有文字层吗、目录能用吗
python scripts/extract.py "D:/书/xxx.pdf" # 按章切分，保留页码
python scripts/build_index.py # 建索引
python scripts/query.py 痛苦 死亡 # 检索，每条带坐标
python scripts/query.py --trace 我思故我在 # 追最早出处
python scripts/coverage.py --next # 我这一栏还缺谁
```

脚本用自身位置定位库，**从任何目录执行都能跑**，不必先 cd。

也可以完全不跑脚本：往 `library/` 丢一个带 frontmatter 的 md 就能用，最小格式见 `SKILL.md`。

## 三个设计判断

**一、按章切，不按整本也不按段。** 整本命中后要读半本书；切成段落，论证就断链，因为哲学论证是跨段推进的。

**二、不做向量检索。** 哲学要的是「这句原话在哪一页」，语义检索给的是「这段话意思接近」——在你这个场景里是负资产，它会把海德格尔和鸡汤判成高相似度。

**三、页码是纸书页，不是 PDF 物理页。** 两者常差几十页，脚本从页眉反推偏移，标 `<!-- p.N -->`。没有这一层，引用就废了。

## 版权边界

这个仓库**只发框架、书目与自己的判断，不发他人正文**。

| 层 | 是否随仓库分发 |
|---|---|
| 脚本、目录约定、地图、排序规则 | 是 |
| 书目（作者／著作／版次／译者／定位符） | 是 |
| 自己写的判断与主题 | 是 |
| 非公有领域的正文全文 | **否** |

`library/01-sources/` 里的条目多数只有书目没有正文，`pack.py` 会强制剥掉非公版正文——这是硬逻辑，没有开关。

一本书属公有领域，不等于手上这一版属公有领域：译本、校注另有著作权。原文公版的可以带走，中译本不行。

## 缺的书怎么补

包里给的是坐标，取得是你的动作。`resolve.py` 只内置公有领域全文源与馆藏入口：

```bash
python scripts/wanted.py --resolve # 我缺哪些书、去哪合法取得
```

Gutenberg / Perseus / ctext / archive.org / Open Library / WorldCat。没有别的。

## 现状

这是**可用但很早期的版本**。库里目前只有两部著作的原文，13 个「苦因」分类里 1 类有材料。它在等更多书进来，而不是在等功能。

扩展点四层，三层不用改代码：内容（往 `library/` 丢 md）、排序（改 `config/order.json`）、书源（`config/providers.json`）、能力（`scripts/` 加脚本，`import _common` 即可复用全库读写）。
